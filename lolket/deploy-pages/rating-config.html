📐 레이팅 수식
최종 레이팅 = 기본 레이팅 + ((승률점수 × W1) + (AI점수 × W2) + (KDA점수 × W3)) × 포지션보정 × 경기수보정
단, W1 + W2 + W3 = 1.0 이 되어야 합니다

1. 수식 가중치 설정
승률점수·AI점수·KDA점수의 배율 (세 값의 합이 반드시 1.0이어야 합니다)
승률 점수 배율 W1 배
AI 점수 배율 W2 배
KDA 점수 배율 W3 배
✓ 합계: 1.00 (정상)
2. 기본 레이팅 (티어별)
마스터 이상은 기본값 + 리그 포인트 1점당 1점 추가
티어4단계3단계2단계1단계
3. 승률 점수 설정
승률 점수 = (승률% − 50) × 배율  (50% 기준, 그 이상이면 양수, 이하면 음수)
예: 승률 58%, 배율 8 → (58 − 50) × 8 = 64점
승률 점수 배율 배
4. AI 점수 설정
평균 AI 점수 구간별 부여 점수 (음수 가능)
구간기준점수
최상위AI ≥ 80점
상위56 ≤ AI < 80점
중위45 ≤ AI < 56점
하위30 ≤ AI < 45점
최하위AI < 30점
5. KDA 점수 설정
평균 KDA 구간별 부여 점수 (음수 가능)
구간기준점수
최상위KDA ≥ 4.0점
상위3.0 ≤ KDA < 4.0점
중위1.5 ≤ KDA < 3.0점
하위KDA < 1.5점
6. 포지션 보정치
각 포지션 × 티어 구간별 보정 배율 (각 구간 합계는 5.0 권장)
포지션 아이언~골드1 플래4~다이아3 다이아2~마스터+
합계 5.00 5.00 5.00
7. 경기수 보정치
경기수 보정치 = MIN(1, 경기수 ÷ 기준판수) — 기준판수 미만이면 비례 감소
MIN(1, 경기수 ÷ 50)
