룽잉닷컴 이용 가이드

룽잉닷컴은 리그오브레전드 커뮤니티 내전을 손쉽게 진행할 수 있는 플랫폼입니다.
멤버 등록부터 팀 구성, 대진표, 결과 기록까지 내전의 모든 과정을 지원합니다.

⚔️
내전 관리
일반·라인 고정·경매 방식으로 팀을 구성하고 대진표를 생성합니다.
📡
실시간 관전
비회원도 링크 하나로 내전 진행 상황을 실시간으로 확인할 수 있습니다.
⭐
레이팅 시스템
내전 결과에 따라 멤버별 레이팅이 자동으로 가감됩니다.
💬
디스코드 연동
내전 알림, 결과 공유, 후기 DM 발송을 디스코드로 자동화합니다.
📄
패치노트
최신 LOL 패치노트를 챔피언·아이템별로 한눈에 확인할 수 있습니다.
📋
외전 모집
커뮤니티 간 5v5 외부 경기 모집글을 올리고 신청할 수 있습니다.
👥
역할 구분
접근 가능한 기능이 역할마다 다릅니다
역할 설명 주요 권한
비회원 로그인 없이 이용 관전, 패치노트, 외전 신청, 경매 호가(팀장 코드 인증 후)
일반 관리자 커뮤니티별 관리자 계정 자신의 커뮤니티 내전 전체 관리, 멤버 등록/삭제, 팀 구성, 결과 입력
마스터 관리자 플랫폼 최고 관리자 모든 커뮤니티 접근, 커뮤니티 생성/삭제, 관리자 계정 발급, 공지사항 관리
ℹ️
관리자 계정은 직접 가입할 수 없습니다. 마스터가 발급한 초대 링크를 통해서만 계정을 만들 수 있습니다. 커뮤니티를 새로 만들고 싶다면 커뮤니티 신청 섹션을 참고하세요.
👁
관전 모드
로그인 없이 내전을 실시간으로 확인하는 방법
ℹ️
관리자가 공유한 내전 링크로 접속하면 자동으로 관전 모드로 진입합니다. 별도의 로그인이 필요하지 않습니다.
📡 관전 화면에서 볼 수 있는 정보
  • 현재 단계 표시: 멤버 등록 → 팀 짜기 → 대진표 → 결과 입력 단계를 상단 진행 바로 확인
  • 멤버 목록: 참여 멤버의 티어, 주/보조 포지션, 레이팅 점수, 디스코드 연동 여부
  • 팀 구성: 확정된 팀과 팀원 구성을 카드 형태로 확인
  • 대진표: 토너먼트 대진표와 진행 현황
  • 결과: 매치 결과, 스코어보드, 최종 순위
  • 경매 진행 상황: 경매 내전의 경우 현재 경매 중인 선수와 현재가 실시간 표시
🔄 실시간 업데이트
관전 화면은 Firebase 실시간 데이터베이스와 연동되어 있어, 관리자가 변경사항을 저장하면 즉시 자동으로 반영됩니다. 새로고침 없이도 최신 상태를 확인할 수 있습니다.
🔨
경매 내전 — 팀장 호가 참여
경매 내전에서 팀장으로 지정된 경우 비회원도 호가 입력 가능
⚠️
호가 참여는 경매 내전(Auction)에서 팀장으로 지정된 경우에만 가능합니다. 일반 내전에서는 관전 기능만 이용할 수 있습니다.
1
관전 링크로 접속
관리자가 공유한 내전 링크로 접속합니다.
2
입찰 탭 선택
관전 화면 하단의 입찰 탭을 선택합니다.
3
팀장 코드 입력
관리자에게 받은 팀장 인증 코드를 입력합니다.
팀장 코드란? 관리자가 대진표/팀 구성 화면에서 팀장에게 별도로 전달하는 숫자 코드입니다.
4
호가 입력
현재 경매 중인 선수가 표시되면 포인트를 입력하고 호가 버튼을 누릅니다. 최고가를 제시한 팀장이 해당 선수를 낙찰받습니다.
📋
외전 모집
다른 커뮤니티와 5v5 경기를 신청하거나 모집글을 확인하는 기능
비회원이 할 수 있는 것
  • 모집글 열람: 다른 커뮤니티가 올린 외전 모집글과 조건(티어, 일시, 포지션)을 확인
  • 북마크: 관심 있는 모집글을 북마크하여 나중에 다시 볼 수 있음
  • 댓글: 모집글에 댓글로 문의 또는 소통
  • 신청: 신청 폼을 통해 팀 정보를 입력하고 경기를 신청
  • 마감 확인: 모집 마감까지 남은 시간 카운트다운 표시
📄
패치노트 페이지
최신 LOL 패치 정보를 확인하는 방법
ℹ️
패치노트 페이지(roonging.com/patch)는 로그인 없이 누구나 이용할 수 있습니다.
주요 기능
  • 버전 탭: 상단 탭을 클릭해 패치 버전을 전환합니다. 탭 전환 시 슬라이드 애니메이션이 적용됩니다.
  • 챔피언 / 아이템 탭: 하단 탭에서 챔피언 변경사항과 아이템 변경사항을 구분해서 볼 수 있습니다.
  • 필터: 전체 🟢 버프 🔴 너프 🟡 조정 중 선택해 원하는 유형만 볼 수 있습니다.
  • 검색: 챔피언 또는 아이템 이름으로 검색이 가능합니다.
  • 상세 팝업: 챔피언·아이템을 클릭하면 변경된 수치와 스킬 이미지를 팝업으로 확인할 수 있습니다.
🔑
관리자 로그인
관리자 계정으로 로그인하는 방법
1
초대 링크로 계정 생성
마스터 관리자에게 초대 링크를 받아 아이디/비밀번호를 설정합니다. 초대 링크 없이는 계정을 만들 수 없습니다.
2
헤더 우측 로그인 버튼 클릭
메인 페이지 우측 상단의 로그인 버튼을 클릭하고 아이디·비밀번호를 입력합니다.
로그인 세션은 8시간 동안 유지됩니다. 세션이 만료되면 자동으로 로그아웃됩니다.
3
커뮤니티 선택
로그인 후 내 커뮤니티가 자동 선택됩니다. 마스터는 드롭다운에서 다른 커뮤니티로 전환할 수 있습니다.
1️⃣
1단계 — 멤버 등록
소환사를 검색해 내전 참가 멤버를 등록하는 단계
ℹ️
이 단계를 시작하려면 먼저 내전을 생성해야 합니다. 홈 화면(내전 목록)에서 + 내전 생성 버튼을 눌러 이름, 일시, 진행자를 입력하세요.
소환사 검색 및 추가
1
닉네임#태그 입력
오른쪽 검색란에 소환사명을 닉네임#태그 형식으로 입력합니다. 태그 없이 입력하면 #KR1이 자동 적용됩니다.
예시: 페이커#KR1 또는 Hide on bush#KR1
2
검색 결과 확인
검색 결과 카드에 소환사의 레벨, 솔랭 티어, 전 시즌 최고 티어가 표시됩니다.
3
주 포지션 선택
탑 / 정글 / 미드 / 원딜 / 서폿 중 주 포지션 1개를 선택합니다.
4
보조 포지션 선택 (선택)
보조 포지션을 하나 이상 선택할 수 있습니다. 라인 고정 내전에서 팀 배정에 활용됩니다.
5
멤버 추가 클릭
멤버 추가 버튼을 눌러 명단에 등록합니다. 이미 등록된 소환사는 중복 추가되지 않습니다.
티어 수동 오버라이드: 솔랭 티어와 내전 실력이 다를 경우, 검색 결과 아래의 티어 조정 버튼으로 수동 설정할 수 있습니다.
출석 체크
  • 등록된 멤버 카드 우측의 출석/미출석 버튼으로 당일 참가 여부를 표시합니다.
  • 전체 출석 버튼으로 모든 멤버를 한 번에 출석 처리할 수 있습니다.
  • 다음 단계로 넘어가려면 인원이 10의 배수이고 전원 출석 상태여야 합니다.
디스코드 연동 멤버 불러오기
  • 디스코드 봇에서 /내전참가 커맨드로 참가 신청한 멤버를 새로고침 버튼으로 불러올 수 있습니다.
  • 불러온 멤버의 정보를 확인한 후 명단에 추가하거나 별도 관리할 수 있습니다.
2️⃣
2단계 — 내전 종류 선택
어떤 방식으로 팀을 구성할지 선택하는 단계
종류 설명 특징
⚔️ 일반 내전 관리자가 직접 드래그앤드롭으로 팀을 편성 자유로운 팀 구성, 자동 밸런싱 지원
🎯 라인 고정 내전 포지션(탑/정글/미드/원딜/서폿)별로 고정 배정 각 라인에 한 명씩 자동/수동 배정, 포지션 보장
🔨 경매 내전 팀장들이 포인트를 소비해 선수를 낙찰받는 방식 팀장 선발, 포인트 배정, 실시간 경매 진행
3️⃣
3단계 — 팀 짜기 (일반/라인 고정)
드래그앤드롭으로 팀을 구성하는 단계
팀 구성 방법
1
대기 풀 확인
왼쪽 대기 풀에 전체 멤버가 표시됩니다. 각 카드에는 티어와 포지션이 표시됩니다.
2
팀에 드래그앤드롭
멤버 카드를 오른쪽 팀 패널로 드래그해서 팀에 배정합니다. 팀 간 이동도 드래그로 가능합니다.
3
자동 밸런싱 (선택)
자동 밸런싱 버튼을 누르면 티어 점수 기반으로 팀이 균등하게 자동 배분됩니다.
언랭크 주의: 언랭크 멤버가 있으면 티어 계산에서 제외할지 묻는 확인창이 나타납니다.
4
팀장 지정
각 팀 패널에서 팀장 지정 버튼으로 팀장을 설정합니다. 팀장은 경매 내전에서 호가 권한을 가집니다.
라인 고정 내전 추가 방법
  • 각 라인(탑/정글/미드/원딜/서폿)에 한 명씩 배정하는 방식으로 진행됩니다.
  • 멤버의 주 포지션을 기준으로 자동 분류되며, 필요시 수동 조정도 가능합니다.
  • 포지션 충돌 시 보조 포지션을 기준으로 대체 배정됩니다.
🔨
3단계 — 경매 내전
팀장이 포인트를 사용해 선수를 낙찰받는 방식
경매 진행 순서
1
팀장 선발 및 포인트 설정
팀장을 지정하고 각 팀장에게 초기 포인트를 부여합니다. 포인트는 선수 입찰에 사용됩니다.
2
경매 시작 — 선수 공개
관리자가 경매 중인 선수를 한 명씩 공개합니다. 화면에 해당 선수의 티어와 포지션이 표시됩니다.
3
호가 입력
각 팀장이 원하는 포인트를 입력해 호가합니다. 현재 최고가가 실시간으로 업데이트됩니다.
비회원 팀장: 관전 링크로 접속해 팀장 코드 인증 후 직접 호가 입력이 가능합니다.
4
낙찰 확정
관리자가 낙찰 버튼을 누르면 최고가 팀장의 팀에 해당 선수가 배정되고 포인트가 차감됩니다.
5
전원 낙찰까지 반복
모든 선수의 낙찰이 완료될 때까지 반복합니다. 낙찰 이력은 경매 로그에 기록됩니다.
미낙찰 처리: 유찰된 선수는 별도 공간에 모아 관리자가 수동 배정할 수 있습니다.
경매 진행 도중 유용한 기능
  • 호가 잠금: 특정 구간에서 호가를 일시 중단할 수 있습니다.
  • 경매 로그: 입찰·낙찰·유찰 이력이 실시간으로 기록됩니다.
  • 포인트 현황: 각 팀장의 잔여 포인트가 항상 표시됩니다.
  • 디스코드 연동: 경매 결과를 디스코드 채널로 자동 공유할 수 있습니다.
4️⃣
4단계 — 대진표
토너먼트 대진표를 생성하고 관리하는 단계
대진표 생성 및 관리
  • 자동 생성: 대진표 생성 버튼을 누르면 팀이 무작위로 배치된 토너먼트 대진표가 생성됩니다.
  • 재추첨: 마음에 들지 않으면 재추첨 버튼으로 다시 뽑을 수 있습니다.
  • 수동 교체: 특정 대진의 팀을 수동으로 교체할 수 있습니다.
  • 추가 대진: 기본 대진 외에 추가 경기를 등록할 수 있습니다.
  • 대진표 복사: 이미지 복사 버튼으로 대진표를 이미지로 복사해 공유할 수 있습니다.
  • 링크 복사: 관전 링크를 복사해 멤버들에게 공유할 수 있습니다.
ℹ️
이 단계에서 관전 링크를 멤버들에게 공유하면, 멤버들이 관전 화면에서 자신의 팀 배정과 경기 일정을 확인할 수 있습니다.

  • 후기 DM 발송: 디스코드로 참여한 멤버 전원에게 내전 후기 링크를 DM으로 발송합니다.

기능 설명 설정 위치
내전 참가 봇 멤버가 /내전참가 디스코드 커맨드로 직접 참가 신청 커뮤니티 설정 → 디스코드 서버 ID 등록

⭐
레이팅 시스템
내전 결과에 따라 자동으로 점수가 가감되는 랭킹 시스템
레이팅 작동 방식
  • 자동 가감: 경기 결과를 저장하면 승팀 멤버는 레이팅이 오르고, 패팀 멤버는 내려갑니다.
  • 티어별 차등: 높은 티어 팀이 낮은 티어 팀을 이기면 획득 점수가 적고, 반대의 경우 더 많이 얻습니다.
  • 글로우 효과: 레이팅 2000+부터 카드에 글로우 효과가 적용됩니다 (2000→금색, 2500→주황, 3000→빨강).
  • 원복 처리: 결과를 삭제하면 레이팅도 자동으로 원복됩니다.
  • 시즌제: 시즌별로 레이팅이 분리 관리됩니다. 시즌 종료 후 새 시즌에서 초기화됩니다.
  • 승률 랭킹: 홈 화면 사이드바에서 커뮤니티 내 승률 랭킹을 확인할 수 있습니다.

개인 상세 전적

소환사명 클릭 시 열리는 심층 분석 모달

전적 표에서 소환사명을 클릭하면 해당 멤버의 개인 상세 전적 모달이 열립니다. 6개의 탭으로 구성되어 있습니다.

📊 분석 탭
  • • 기본 스탯 — 총 게임 수, 승률, KDA, 이번 주 게임 수
  • • 챔피언 통계 — 내전에서 플레이한 챔피언별 게임 수·승률·KDA. 승률이 낮은 챔피언은 빨간색으로 강조
  • • 포지션 분포 — 주로 플레이한 포지션 비율 시각화
  • • 아군/상대 궁합 — 함께할 때 승률이 높은 아군 TOP 5, 상대했을 때 이기기 어려운 상대 TOP 5
  • • 최근 경기 목록 — 최근 내전 게임 결과 및 챔피언 확인
📈 레이팅 로그 탭
시즌 중 레이팅이 어떻게 변화했는지 게임별 내역을 타임라인으로 확인합니다. 각 게임에서 레이팅이 올랐는지 내렸는지, 얼마나 변동했는지 상세 항목별로 표시됩니다.
🎯 주간 미션 탭
관리자가 설정한 이번 주 주간 미션 현황과 해당 멤버의 달성 여부를 확인합니다.
💬 코멘트 탭
관리자가 해당 멤버에 대해 남긴 코멘트(특이사항, 메모 등)를 확인합니다.
🗺️ 히트맵 탭
요일·시간대별 내전 참여 패턴을 히트맵으로 시각화합니다. 어느 시간대에 내전을 자주 하는지 한눈에 파악할 수 있습니다.
🏷️ 닉네임 탭
해당 멤버의 닉네임 변경 이력을 확인합니다.
💡
모달 상단의 딥롤 바로가기 버튼을 누르면 해당 소환사의 딥롤 페이지가 새 탭으로 열립니다.

레이팅 변화 랭킹

이번 시즌 레이팅 상승/하락 TOP 랭킹

상단 탭에서 📈 레이팅 변화를 클릭하면 이번 시즌 동안 레이팅이 가장 많이 오른 멤버와 가장 많이 떨어진 멤버를 순위별로 확인할 수 있습니다.

⭐ 레이팅이란?
내전 10판 이상 참여한 멤버에게 부여되는 커뮤니티 전용 점수입니다. 승패 외에도 KDA, 승률, 티어 등 여러 항목을 종합해 산출됩니다. 각 항목별 점수는 전적 표에서 레이팅 뱃지에 마우스를 올리면 확인할 수 있습니다.
ℹ️
레이팅은 시즌 단위로 관리됩니다. 관리자가 새 시즌을 시작하면 이전 시즌 기록은 보존되고 레이팅이 초기화됩니다.

요일별 내전 빈도를 비교합니다. 주말에 몰리는지, 특정 요일이 높은지 파악할 수 있습니다.
🏅
챔피언 픽율 TOP
커뮤니티 내전에서 가장 많이 선택된 챔피언 순위를 확인합니다.

MVP / 최다 참여
시즌 MVP 및 개근상(최다 참여) 수상자를 확인할 수 있습니다.

스카우트 보고서

특정 멤버를 내 팀에 데려올 때 참고하는 심층 분석

상단 탭에서 🔭 스카우트를 선택하면 특정 멤버의 성향과 강점을 분석한 보고서를 생성할 수 있습니다. 팀 구성 전에 활용하면 유용합니다.

📄 보고서에 포함되는 내용
  • ▸포지션 적합도 — 각 포지션에서의 실제 게임 수와 성과를 종합한 적합도 점수
  • ▸챔피언 풀 — 자주 쓰는 챔피언과 각 챔피언의 승률·숙련도
  • ▸시너지 분석 — 함께할 때 승률이 높은 아군 멤버 목록
  • ▸상대 기록 — 특정 멤버를 상대했을 때의 승률
  • ▸최근 폼 — 최근 10경기 기준 승률 트렌드
💡
경매 내전에서 팀장이 멤버를 지명하기 전, 스카우트 보고서를 미리 확인해두면 더 효율적으로 팀을 구성할 수 있습니다.

기타 관리 기능

관리자 전용 — 전적 페이지 운영 도구

관리자로 로그인하면 전적 페이지 우측 상단에 추가 버튼들이 활성화됩니다.

👑 초기 레이팅 계산 관리자
새 시즌을 시작하거나 레이팅을 처음 도입할 때, 기존 전적 데이터를 기반으로 초기 레이팅을 일괄 계산합니다.
🎯 주간 미션 설정 관리자
이번 주 달성 목표(예: 3판 이상 참여, 승률 60% 이상 등)를 설정합니다. 미션이 설정되면 멤버 개인 상세 전적의 주간 미션 탭에 표시됩니다.
🔄 최고티어 전체 업데이트 관리자
등록된 모든 멤버의 역대 최고 티어 정보를 Riot API에서 일괄 갱신합니다. 시즌 초기화 후 실행하면 정확한 데이터를 유지할 수 있습니다.
🏷️ 닉네임 변경 이력 탭
상단 탭에서 선택 가능한 뷰입니다. 특정 닉네임으로 검색해 해당 소환사의 이전 닉네임 변경 내역을 추적할 수 있습니다. 멤버가 닉네임을 바꿨을 때 동일 인물인지 확인하는 데 유용합니다.
🎯 임시 티어 관리 탭 관리자
